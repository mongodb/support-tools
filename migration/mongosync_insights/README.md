# Mongosync Insights (moved)

**Mongosync Insights** is no longer maintained in the [mongodb/support-tools](https://github.com/mongodb/support-tools) repository.

It has been renamed to **Migration Monitoring Insights** and lives in a dedicated public repository:

**https://github.com/mongodb/migration-monitoring-insights**

Historical Mongosync Insights releases previously published from this support-tools tree remain available on the support-tools GitHub Releases page; all new development and releases happen in the repository above.
